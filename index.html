syntax

field:value filters; anything without a colon is plain text. > >= < <= work on class, road, dist, gain and the four risk ratings. Terms combine with AND.

class
1, 2, 3, 4, 5
exposure, rockfall, routefinding, commitment
low, moderate, considerable, high, extreme
road
0 paved … 6 difficult 4WD
dist, gain
miles, feet
range
sawatch, sangre, elk, front, mosquito, juan, tenmile
snow, summited, planned
yes, no
scope
standard (the default), any
kind
route, combo, approach — narrows to that route type

Route fields test the standard route, and the Standard column shows it. scope:any, or the any route chip, tests every way up the peak; kind:combo, or the route-type select, tests only combos. The column follows either way, naming the route that satisfied the query, so the difficulty and road on a row belong to the route you filtered for. One route has to satisfy every route field at once. The selects and chips are shortcuts that write terms into this box, so the query is the whole filter.
